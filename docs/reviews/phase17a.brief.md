- **Phase and goal:** todo.md item 4.10, first half (see its "Split" and "Done (17a)" bullets). The main process reads a site's Wi-Fi networks through the Omada Open API: the paginated v2 SSID catalog, the v1 detail and the v1 per-SSID AP-group bindings. It validates them with pure validators that reject malformed payloads, builds an allowlist-only renderer DTO (`ManagedNetwork`, `hasPassphrase` only, no secret at any depth), detects the "All access points" scope (`chooseDevices = 0`, anything unrecognized = unknown scope, never "all") and applies the enable-field fallback. It serves the result over a new guarded IPC channel, `management:networks`, using the session nonce. No UI; phase 17b adds the renderer view.
- **Spec:** `docs/management-design.md` §2.2–§2.3, §3 (secrets never reach the renderer), §4.5, §5 (defensive defaults); API: SSID sections of `docs/omada-openapi-ops.md`. Pattern copied: phase 16a (`docs/progress-archive/phase-16a.md`).
